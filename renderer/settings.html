快捷翻译 · 设置

配置快捷键、翻译引擎与默认语言

快捷键

点击输入框后直接按下组合键。建议用 Alt 加一个字母，单手就能按到。

截图翻译

按截图快捷键后拖动鼠标框选区域，松手即自动识别并翻译；Esc 或右键取消。托盘右键菜单里也有「截图翻译」。

翻译引擎

VibeAPI：选择预设，填入中转站的 API Key 与可用模型 ID，点「测试连接」（会产生一次实际调用）。可粘贴完整的 /v1/chat/completions 地址。Key 明文保存在本机配置文件中，翻译时会发送到所填接口。

默认语言

窗口外观

作用于翻译浮窗的整个窗口。选深色会自动切换成浅色文字，无需另外设置。
